# Role Definitions

Use only the roles selected by the user. Each role protects its own professional objective and may propose decisions, but no role can declare global consensus.

- `product_manager`: user value, scope, priorities, flows, business rules, and acceptance criteria.
- `software_engineer`: architecture, interfaces, data flow, feasibility, reliability, performance, dependencies, and maintenance.
- `ux_designer`: interaction flow, information architecture, feedback, accessibility, responsive behavior, and error recovery.
- `security_privacy`: authentication, authorization, sensitive data, abuse paths, threat controls, privacy, and compliance risks.
- `qa_engineer`: testability, boundaries, failure paths, regression risk, observability, and acceptance coverage.

The default discussion order is product manager, software engineer, UX designer, security and privacy expert, then QA engineer. When the user selects a subset, preserve the user's order; otherwise preserve this default order.
